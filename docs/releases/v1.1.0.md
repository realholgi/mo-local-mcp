## mo-local-mcp 1.1.0

Version 1.1.0 erweitert die Schlüsselwiederherstellung für Programmdateien ohne bekanntes Hashprofil.
Der MCP-Zugriff und die Fachabfragen bleiben unverändert.

## Änderungen gegenüber v1.0.0

- `mo-schluessel-wiederherstellen` sucht bekannte Konstantenmuster ohne feste Tabellenposition.
  Die Suche unterstützt Universal-Mach-O-Dateien und einzelne ARM64-Mach-O-Dateien.
- Die neue Option `--datenbank` prüft Schlüsselkandidaten durch lesenden Zugriff auf das Datenbankschema.
  Bei unbekanntem Datei-Hash ist diese Option erforderlich.
  Nur genau ein passender 32-Byte-Schlüssel wird gespeichert.
- Bekannte Hashprofile bleiben erhalten. Mit `--datenbank` lassen sich auch deren Schlüssel prüfen.
- Die Mustersuche wurde mit MonKey Office 2024 21.4.3 geprüft, ohne die App zu starten.
  Dafür war kein neues Hashprofil nötig.
- README und Installationsanleitung beschreiben die Paketinstallation und die erweiterte Schlüsselprüfung.
- Der Release-Workflow verwendet versionierte Releasehinweise.
  Fehlende oder leere Hinweise stoppen die Veröffentlichung.

## Voraussetzungen und Grenzen

Du benötigst macOS, Python ab 3.13 und [uv](https://docs.astral.sh/uv/).
Verwende nur einen geschlossenen, ruhenden und konsistent abgeschlossenen Datenbankstand.
Die Datenbank bleibt schreibgeschützt. Nichtleere WAL- oder Journaldateien werden abgelehnt.

Die Suche erkennt bekannte Konstantenaufbauten an anderen Positionen.
Geänderte Zeichenreihenfolgen, Tabellenformate oder Verschlüsselungsverfahren benötigen weiterhin eine Anpassung am Leser.
Ein passender Schlüssel bestätigt weder die Unterstützung aller Datenbankschemata noch die Unversehrtheit aller Geschäftsdaten.

## Installation und Aktualisierung

```sh
uv tool install --force --python 3.13 \
  "https://github.com/realholgi/mo-local-mcp/releases/download/v1.1.0/mo_local_mcp-1.1.0-py3-none-any.whl"
```

Beende vor einer Aktualisierung den MCP-Prozess. Starte danach den MCP-Client neu.
Vorhandene Schlüsseldateien bleiben erhalten. Eine erneute Wiederherstellung ist dafür nicht nötig.

Für eine unbekannte Programmdatei:

```sh
mo-schluessel-wiederherstellen \
  --programmdatei "/pfad/zur/MonKey Office.app/Contents/MacOS/MonKey Office" \
  --datenbank /absoluter/pfad/entwicklungsstand.db
```

Das Release enthält das Wheel, das Quellpaket und `SHA256SUMS`.
MonKey Office, Datenbanken und Schlüssel sind nicht enthalten.
Prüfsummen und die MCP-Client-Konfiguration erklärt die
[Einrichtung](https://github.com/realholgi/mo-local-mcp/blob/v1.1.0/docs/einrichtung.md).
